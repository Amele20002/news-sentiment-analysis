# News Sentiment Analysis

## Project Overview

This project analyzes financial news headlines and historical stock price data to explore the relationship between news sentiment and stock market movement.

The project is part of the Week 1 Challenge: Predicting Price Moves with News Sentiment.

## Business Objective

Nova Financial Solutions wants to improve financial forecasting accuracy by combining news sentiment analysis with stock price movement analysis.

## Task 1: Exploratory Data Analysis

Task 1 focuses on understanding the financial news dataset through exploratory data analysis.

### Objectives

- Set up a professional Python project structure
- Configure Git and GitHub workflow
- Set up CI/CD using GitHub Actions
- Load and inspect the financial news dataset
- Analyze headline lengths
- Analyze publisher activity
- Analyze publication trends over time
- Extract common keywords and phrases from headlines
- Produce visualizations and summarize insights
